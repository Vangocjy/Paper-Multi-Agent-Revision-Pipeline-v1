# style_dimensions.md

Use this file to keep template integration focused on structure, not science.

## Integration dimensions

### 1. front matter
Check:
- title block
- author and Affiliation format
- abstract placement
- keyword placement

### 2. body structure
Check:
- section depth
- heading conventions
- acknowledgments and appendices placement if present

### 3. references
Check:
- bibliography command pattern
- citation command compatibility
- template-specific reference style wiring

### 4. template-native conventions
Prefer:
- native environments
- native commands
- minimal custom macros

### 5. wording preservation
For any local wording adjustment introduced during integration, keep it narrow and record it in the format report.
