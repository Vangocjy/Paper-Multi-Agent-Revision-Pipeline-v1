# style_dimensions.md

Use this file as a compact latex-side repair checklist.

## Repair dimensions

### 1. figures and tables
Check:
- valid environment structure
- caption presence and consistency
- label placement consistency
- subfigure handling only if already supported by the template

### 2. equations
Check:
- valid display environments
- alignment syntax consistency
- label presence where references exist
- numbering behavior consistent with template conventions

### 3. cross-references
Check:
- duplicate labels
- missing refs
- obvious mismatches between labels and mentions

### 4. bibliography
Check:
- citation command consistency
- bibliography include pattern
- compatibility between `.bib`, style path, and template

### 5. boundary safety
Before changing words, ask:
- is this a formatting necessity?
- can the fix be done without changing meaning?
- should this instead be logged for writer?
