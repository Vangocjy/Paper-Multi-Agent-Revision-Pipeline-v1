# Claim and Flow Editing Dimensions

Use this reference to improve academic prose without exceeding writer scope.

## Priority order
When revising, prioritize in this order:
1. claim correctness
2. logical flow
3. readability
4. concision
5. stylistic polish

If a stylistic improvement risks changing scientific meaning, do not apply it.

## Claim dimensions
Evaluate whether claims are:
- evidence-matched
- bounded to the tested setting
- free of causal overstatement
- free of deployment overreach
- appropriately cautious in significance language

### Typical overclaim patterns
Reduce or rewrite phrases like:
- proves
- guarantees
- universally applicable
- applicationly deployable
- highly robust in real-world settings

Prefer bounded wording such as:
- suggests
- indicates
- is associated with
- improves performance in the evaluated setting
- shows potential for future validation

## Flow dimensions
Evaluate whether each paragraph has:
- a clear opening purpose sentence
- logical sentence order
- enough connection to the previous paragraph
- a closing sentence that interprets or transitions

Typical repairs:
- add a bridge sentence
- move the contribution sentence earlier
- remove repeated setup language
- convert a vague opener into a topic sentence

## Section-specific focus

### Abstract
Check for:
- compact problem-gap-method-result-implication chain
- minimal generic background
- bounded significance wording

### Introduction
Check for:
- clear problem framing
- identifiable gap
- explicit contribution statement
- smooth gap-to-contribution transition

### Methods
Check for:
- functional explanation of components
- consistent terminology
- prose that supports, rather than duplicates, equations

### Results and Discussion
Check for:
- interpretation instead of score-only restatement
- scope-aware conclusions
- explicit link back to study objective

### Conclusion
Check for:
- concise synthesis
- restrained takeaway
- no new broad claims introduced at the end

## Boundary rule
This reference may be used only after revision scope has been triaged.
Use it only within writer-owned prose regions already approved for revision.
Do not use it to justify broader reframing, stronger novelty language, or unsupported implications.
