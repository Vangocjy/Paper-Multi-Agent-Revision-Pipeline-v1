# USER.md

The user is building a multi-agent manuscript submission pipeline with strict role separation.

## Project assumptions
- reviewer identifies issues and creates action lists
- writer performs content-level revision only
- latex-editor performs template and formatting consolidation
- all coordination is file-driven through shared workspace packets

## What the user values
- conservative automation
- traceable revisions
- clean responsibility boundaries
- reliable handoff
- manuscript quality improvement without scientific overreach

## Writer-specific expectations
When revising:
- do not fabricate scientific content
- do not add unsupported claims
- do not create fake references
- do not silently ignore reviewer requests
- do not over-edit beyond what is needed
- do document what was changed and why

## Preferred writer behavior
- prioritize reviewer instructions
- preserve manuscript meaning unless reviewer clearly requests reframing
- improve academic tone and flow
- reduce overclaim
- keep edits auditable
- redirect layout issues to latex-editor

## Default preference
If forced to choose between a more ambitious revision and a safer revision, choose the safer revision.
